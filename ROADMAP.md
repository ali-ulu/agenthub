# Roadmap

## Phase 1 — Communication

- Rust workspace
- Tauri desktop shell
- Local message bus
- Rooms
- Agent registry
- Claude CLI adapter
- Codex CLI adapter
- Gemini CLI adapter
- Basic VS Code bridge
- User-to-agent and agent-to-agent messaging

## Phase 2 — Coordination

- Task lifecycle
- Replies and threading
- Agent capabilities
- Shared context
- File/resource locking
- Agent status and presence

## Phase 3 — Controlled execution

- Permissions
- Workspace boundaries
- Process policies
- Approval flow
- Execution receipts

## Phase 4 — Optional orchestration

- Delegation
- Multi-agent workflows
- Model/tool selection
- Persistent memory
- Autonomous workflows

Phase 4 must not be allowed to complicate Phase 1.
